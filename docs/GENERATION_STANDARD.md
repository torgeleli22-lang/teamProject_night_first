# 연습 문항 생성 기준

AI 가 만드는 연습 문항(코드 + ※ 꼭 설명할 곳 + 모범 설명)이 **무엇을 갖춰야 학습자에게 내보낼 수 있는지** 정하는 문서예요.
코드(`lambda/api/practice.py`)의 프롬프트·규칙 검사·AI 검토는 이 문서를 따르고, 기준을 바꿀 때는 이 문서부터 고쳐요.

- 상태: **초안 v0.1** — `## 7. 정해야 할 것` 이 정해지면 v1.0
- 원칙
  - 위 단계가 아래 단계를 정해요: **학습 목표 → 코드 요건 → ※ 지점 → 모범 설명 → 합격 기준 → 실패 처리**
  - 모든 기준에는 **확인 방법**(규칙 · AI 검토 · 사람)이 붙어요. 확인할 수 없는 기준은 기준이 아니라 희망 사항이에요
  - 숫자(줄 수 등)는 학습 목표를 담기 위한 결과예요. 숫자부터 정하지 않아요

---

## 0. 계획 — 단계마다 정할 것

| 단계 | 정할 것 | 결과물 | 확인 방법 |
|---|---|---|---|
| 1. 학습 목표 | 난이도마다 학습자가 따라가고 설명할 수 있어야 하는 흐름, 중심 개념 | 난이도별 목표 표 | 사람 (기준 문서 검토) |
| 2. 코드 요건 | 목표를 담기 위한 필수 요소, 그 단계에서 쓰지 않을 요소, 손으로 따라갈 수 있는 크기, 길이, 실행 조건 | 난이도별 요건 표 | 규칙 + AI 검토 |
| 3. ※ 지점 | 어디를 고르는지, 개수, 범위 크기, 개념 분포 | 선택 기준 표 | 규칙 + AI 검토 |
| 4. 모범 설명 | 무엇을 어떤 순서로, 얼마나 구체적으로 쓰는지, 값 추적 기록 | 작성 기준 + 예시 | 규칙 + AI 검토 |
| 5. 합격 기준 | 1~4 의 각 항목을 어느 단계에서 어떻게 확인하는지 | 기준 ↔ 확인 방법 대응표 | — |
| 6. 실패 처리 | 걸렸을 때 다시 만들기, 예시 코드, 기록 | 처리 흐름 | 규칙 |

## 1. 난이도별 학습 목표

난이도는 **"학습자가 머릿속에 동시에 붙잡고 있어야 하는 것의 양"**으로 나눠요.
입문은 변수 몇 개, 초급은 함수 사이를 오가는 값, 중급은 객체 상태와 건너뛰는 흐름, 고급은 알고리즘 전체의 전략이에요.

| 난이도 | 학습 목표: 학습자가 설명할 수 있어야 하는 것 | 중심 개념 (`CONCEPTS`) | 학습자가 쓸 수 있으면 되는 설명의 예 |
|---|---|---|---|
| **입문** | 위에서 아래로 실행되는 코드에서, **반복과 조건을 지나며 변수 값이 어떻게 바뀌는지** 한 단계씩 따라간다 | `loop_update`, `branch` | "주문을 하나씩 꺼내 가격을 total 에 더해서, 반복이 끝나면 10000 이 돼요" |
| **초급** | **함수를 부르면 값이 넘어갔다가 돌아오는 흐름**을 따라가고, 리스트·딕셔너리가 어떻게 바뀌는지 설명한다 | `call_flow`, `data_update` (+ 입문 개념) | "sell 이 check_stock 을 불러 '품절'을 받으면 판매를 막고 False 를 돌려줘요" |
| **중급** | **객체 상태 변화, 예외로 건너뛰는 흐름, 재귀 호출**처럼 위에서 아래로 읽으면 놓치는 흐름을 따라간다 | `class_state`, `exception`, `recursion` (+ 아래 단계 개념) | "잔액보다 많이 빼려 하면 예외가 나서 아래 줄은 실행되지 않고 except 로 가요" |
| **고급** | 자료구조와 **알고리즘이 문제를 푸는 전략**(무엇을 기준으로 고르고, 언제 값을 갱신하고, 언제 멈추는지)을 설명한다 | `algorithm` (+ 아래 단계 개념) | "힙에서 가장 가까운 역을 꺼내, 더 짧은 길이 나오면 거리를 갱신해요" |

- 위 단계는 아래 단계의 개념을 포함해요 (중급 코드에도 반복·조건·함수 호출이 있어요)
- 각 단계의 **중심 개념**이 그 문항의 ※ 지점에 꼭 들어가야 해요 (3장)

## 2. 코드 요건

### 2.1 난이도별 요건
| 항목 | 입문 | 초급 | 중급 | 고급 |
|---|---|---|---|---|
| 꼭 있어야 하는 것 | 반복 1개 이상, 조건 1개 이상 | 서로 부르는 함수 2개 이상, 리스트 또는 딕셔너리 | 클래스·예외·재귀 중 **2가지 이상**, 함수 4개 이상 | 클래스 1개 이상, 함수 6개 이상, 자료구조 2종 이상, 알고리즘 1~2개, 입력 검증과 예외 |
| 쓰지 않는 것 (한 단계 위 개념) | 함수 정의 2개 이상, 클래스, 예외 처리, 재귀 | 클래스, 재귀 | — | — |
| 손으로 따라갈 수 있는 크기 | 반복은 10번 이하, 목록은 6개 이하 | 반복 10번 이하, 목록 8개 이하, 호출 깊이 3 이하 | 목록 10개 이하, 재귀 깊이 5 이하 | 그래프·표는 노드·칸 12개 이하 |
| 길이 (안내 / 한도) | 10~20줄 / 30줄 이하 | 25~45줄 / 60줄 이하 | 100~130줄 / 100~150줄 | 170~250줄 / **151~300줄** |

- 길이는 사용자가 정한 값(중급 100~150줄, 고급 300줄 이하)을 따르되, **중급과 고급 한도가 겹치지 않게** 고급 최소를 151줄로 해요 (지금은 120줄이라 120~150줄 구간이 겹쳐요)
- "손으로 따라갈 수 있는 크기"가 새로 생긴 기준이에요. 반복이 100번 도는 코드는 문법이 쉬워도 흐름을 설명할 수 없어서예요

### 2.2 모든 난이도 공통
| 항목 | 기준 |
|---|---|
| 실행 | 그대로 실행되어 오류 없이 끝나고, 마지막에 결과를 출력해요 |
| **같은 결과** | 실행할 때마다 출력이 같아야 해요 (모범 설명의 값이 정답이 되려면 필요). random 은 시드를 고정해야 하고, 현재 시각은 결과에 영향을 주지 않아야 해요 |
| 외부 의존 없음 | 입력·파일·네트워크·운영체제·다른 프로그램 실행 없음, 표준 라이브러리만 (Python) / Node.js 기본 기능만 (JavaScript) |
| 주제 | 고른 생활 주제를 실제로 다루는 코드 |
| 이름과 주석 | 이름은 영어, 문자열 값과 주석은 한국어. 주석은 제목 정도로 최소 (주석이 흐름을 대신 설명하면 읽기 연습이 안 돼요) |
| 쓸모없는 코드 없음 | 실행되지 않는 함수, 결과에 쓰이지 않는 계산, 줄 수 채우기용 반복 없음 |

## 3. ※ 꼭 설명할 곳 선택 기준

| 항목 | 기준 |
|---|---|
| 개수 | 입문 1 · 초급 2 · 중급 3 · 고급 5 — **요청한 수와 같아야 통과** (지금은 중급·고급이 2곳이어도 통과) |
| 개념 | **그 난이도의 중심 개념이 1곳 이상** (입문: 반복·조건, 초급: 함수 호출·자료구조, 중급: 객체 상태·예외·재귀, 고급: 알고리즘). 집중 연습이면 절반 이상이 그 개념 |
| 범위 크기 | 한 곳의 줄 수 상한: 입문 8줄 · 초급 12줄 · 중급·고급 20줄 (지금은 상한이 없어 57줄짜리 ※ 도 통과) |
| 실행되는 곳 | 실제로 실행되어 값이나 흐름이 바뀌는 곳 (실행되지 않는 분기, 출력만 하는 줄은 고르지 않음) |
| 겹치지 않기 | 범위끼리 겹치지 않고, 서로 다른 흐름을 짚어요 |
| 시작·끝 줄 | 빈 줄로 시작하거나 끝나지 않아요 |

## 4. 모범 설명 작성 기준

모범 설명은 **첨삭의 정답**이에요. 학습자의 메모를 이것과 비교해 ○△✕ 를 매겨요.

### 4.1 담을 내용 (순서대로)
1. **무엇이 들어오는지**: 그 구간이 시작될 때의 값 (앞에서 이미 바뀐 값 포함)
2. **어떤 흐름을 거치는지**: 조건·반복·호출·예외·재귀 중 그 ※ 지점의 개념
3. **무엇이 되는지**: 구간이 끝났을 때 바뀐 값이나 결과 — **실제 실행 값 1개 이상**

### 4.2 형식
| 항목 | 기준 |
|---|---|
| 길이 | 2~3문장, 250자 이하 |
| 값 | 맨 위부터 실제 실행 순서대로 따라간 값만 쓰고, 마지막 출력과 이어져야 해요 |
| 가정 예시 | 쓰지 않아요 ("예를 들어 ~라면" 대신 이 코드에서 실제로 일어나는 일) |
| 횟수·분기 | 반복·재귀 횟수, 어느 분기가 실행되는지는 실제와 같을 때만 써요 |
| 핵심 표현 | 3~5개, **모범 설명 안에 실제로 들어 있는 말**이어야 해요 (첨삭 규칙 채점이 이걸로 비교) |
| 말투 | 한국어 존댓말 "~해요", 초보자 눈높이 |

### 4.3 값 추적 기록 (논문의 핵심)
- 모범 설명을 쓰기 **전에**, 그 ※ 구간을 지날 때의 변수 값을 줄 단위로 적은 **값 추적 기록**(`trace`)을 먼저 만들어요
  - 예: `8번 줄 total=0 → 9번 줄 total=4500 → 9번 줄 total=12500`
- 모범 설명의 값은 이 기록과 같아야 해요. AI 검토도 판정 전에 자기 값 추적을 먼저 적고 비교해요
- 값 추적 기록은 저장만 하고 화면에는 보내지 않아요 (모범 설명과 같은 규칙)

### 4.4 좋은 예 / 나쁜 예
- 좋은 예: "order 의 메뉴를 하나씩 꺼내 menu 에서 가격을 찾아 total 에 더해요. 아메리카노 3000, 라떼 3500, 라떼 3500 을 더해 반복이 끝나면 total 은 10000원이에요."
- 나쁜 예 (앞의 변화를 놓침): "반납하면 재고가 2권에서 3권으로 늘어요" — 실제로는 다른 회원도 빌려 가서 1권에서 2권
- 나쁜 예 (가정): "예를 들어 다익스트라 15분, BFS 18분이면 다익스트라를 골라요"
- 나쁜 예 (값 없음): "조건에 따라 값을 바꾸고 결과를 돌려줘요"

## 5. 합격 기준 — 어떻게 확인하는지

문항은 아래를 **모두** 통과해야 학습자에게 보여요.

| 기준 | 규칙 검사 (비용 없음, 실행 안 함) | AI 교차 검토 | 비고 |
|---|---|---|---|
| 2.1 꼭 있어야 하는 것 · 쓰지 않는 것 | Python: ast 로 함수·클래스·try·재귀 호출 수를 셈 / JS: 정규식으로 셈 | 난이도와 크게 다르면 문제 | JS 는 규칙이 약해 AI 검토가 보완 |
| 2.1 손으로 따라갈 수 있는 크기 | Python: `range(n)` 의 n, 목록 길이를 셈 (확인 가능한 것만) | 반복·재귀 횟수가 크면 문제 | |
| 2.1 길이 | 줄 수 | — | |
| 2.2 실행·같은 결과·외부 의존 없음 | 금지 모듈·함수, random 시드 고정 여부, 출력 존재 | 실행 오류, 끝나지 않는 반복 | 서버에서 실행하지 않아요 |
| 2.2 쓸모없는 코드 | — | 실행되지 않는 함수·결과에 안 쓰이는 계산이 많으면 문제 | |
| 3 ※ 개수·범위 크기·겹침·시작 줄 | 그대로 셈 | — | |
| 3 ※ 중심 개념 포함 | `concept` 꼬리표 확인 (없으면 규칙으로 추정) | 꼬리표가 실제 코드와 맞는지 | |
| 3 실행되는 곳 | — | 실행되지 않는 구간이면 문제 | |
| 4 모범 설명 형식 | 비어 있지 않음, 길이, 핵심 표현이 설명 안에 있음, "예를 들어" 같은 가정 표현 | — | |
| 4 모범 설명 값의 정확성 | — | 판정 전에 값 추적을 먼저 적고 비교, 틀리면 고친 설명으로 교체 | 같은 모델이라는 한계 (논문 결론) |

- AI 검토 결과는 두 종류예요: **다시 만들 문제**(실행 오류·난이도 불일치·실행되지 않는 ※) / **바로 고칠 것**(모범 설명 값)
- 예시 코드(`samples.py`)는 위 기준을 모두 지키고, 추가로 `npm run verify` 가 **실제로 실행해서** 확인해요

## 6. 실패 처리

| 상황 | 처리 |
|---|---|
| 규칙 검사에 걸림 | AI 검토는 건너뛰고, 걸린 이유 + 고칠 방향(줄일 양, 지킬 개수)을 붙여 **한 번 더** 만들어요 |
| AI 검토에서 다시 만들 문제 | 문제 목록을 붙여 **한 번 더** 만들어요. 고치면서 늘리지 말고 안내 길이 안쪽으로 |
| AI 검토에서 모범 설명만 틀림 | 다시 만들지 않고 고친 설명으로 바꿔요 |
| 두 번째도 걸림 | 같은 언어·난이도(집중 개념이 있으면 그 개념)의 **예시 코드**를 주고 안내 문구를 보여요 |
| AI 를 쓸 수 없음 (꺼짐·월 예산·요청 한도·응답 형식 오류) | 바로 예시 코드. 서비스는 멈추지 않아요 |
| 기록 | 걸린 이유를 단계(규칙·검토·AI 오류)별로 관리자 'AI 호출 기록'에 남겨요 |

## 7. 정해야 할 것 (v1.0 전)

| 항목 | 초안 | 이유 |
|---|---|---|
| 고급 최소 줄 수 | 151줄 (중급 한도와 겹치지 않게) | Python 고급 예시 코드 2개(125·134줄)를 늘려야 해요 |
| 중급·고급 ※ 개수 | 요청 수와 정확히 같아야 통과 | 재생성이 조금 늘 수 있어요 |

| 생각 단계(extended thinking) | 끄고 값 추적 기록(4.3)으로 대체 | 논문과 같은 방식, 응답에 남아 확인할 수 있어요 |
| "손으로 따라갈 수 있는 크기" 숫자 | 2.1 표의 값 | 너무 엄격하면 고급 문항이 어려워져요 |
